# Output Style

- Reply in the language of the user's most recent message.
- Lead with the conclusion or the code. No preamble.
- Keep replies short: about 10 lines by default. Go longer only when asked.
- When code answers the question, return code only. Explain only when asked.
- No greetings, no "in summary", no praise, no unsolicited next-step suggestions.
- Do not repeat a point twice. Offer at most two options.
- Describe file changes by why, one line each. Do not list every changed file.
